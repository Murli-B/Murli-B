### 🔐 Cipher
**Privacy-first password checker & generator**

Live analysis with [zxcvbn](https://github.com/dropbox/zxcvbn) running off the main thread in a **Web Worker**, so typing never stutters.

Generation is cryptographically secure: `crypto.getRandomValues` with unbiased rejection sampling, then a Fisher–Yates shuffle. Passwords never touch a server, cookie, or `localStorage`.

### 🛡️ ssh-sentinel
**Offline SSH brute-force detector (CLI)**

Zero-dependency Python that reads local `auth.log` files, groups failures by source IP in a sliding time window, and escalates to **HIGH** when a successful login follows a burst of failures.

Read-only by design — it never blocks traffic, never uploads a log, never phones home.

## 🛡️ Security engineering I actually ship

Not decoration — every one of these is in the code:

| Practice | Implementation |
| --- | --- |
| **Unbiased randomness** | `crypto.getRandomValues` with rejection sampling, never `Math.random()` |
| **Shuffle correctness** | Fisher–Yates, so character positions are genuinely uniform |
| **Thread isolation** | Password analysis runs in a Web Worker — secrets never block the UI thread |
| **Zero exfiltration** | No backend, no cookies, no `localStorage`, no analytics, offline-capable builds |
| **Safe parsing** | Recursive-descent parser instead of `eval` / `Function()` |
| **Safe rendering** | No `innerHTML` / `dangerouslySetInnerHTML` anywhere in the codebase |
| **Type safety** | TypeScript `strict: true` across app, config, and tests |
| **Detection rules** | Sliding-window brute-force thresholds with success-after-failure escalation |
